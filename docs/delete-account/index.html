앱에서 직접 지울 수 있습니다. 앱을 이미 지우셨거나 로그인할 수 없다면 아래 메일로 요청하시면 됩니다.

앱에서 삭제하기

  1. 어디뒀지 앱을 엽니다
  2. 오른쪽 아래 더보기 탭
  3. 맨 아래 탈퇴하기
  4. 확인하면 즉시 처리됩니다

무엇이 지워지나요

항상 지워지는 것

  • 로그인 계정 — 이메일 주소를 포함한 인증 정보가 삭제됩니다. 다시 로그인할 수 없습니다.
  • 이름과 프로필 사진 — 지워지고 표시 이름이 "탈퇴한 사용자"로 바뀝니다.

혼자 쓰던 집이라면

그 집의 모든 데이터가 함께 삭제됩니다.

  • 장소·박스·물건과 사진 전부
  • 변경 이력, 살 것 목록, 초대 코드

가족이 남아 있다면

남은 사람들의 집은 그대로 유지되어야 하므로, 아래는 남습니다.

남는 것 회원님이 등록했던 물건·장소·박스와 그 사진 — 남은 가족의 것이기 때문입니다. 변경 이력에는 이름 대신 "떠난 구성원"으로만 표시됩니다.
넘어가는 것 회원님이 관리자였다면 관리자 권한이 다른 구성원에게 자동으로 넘어갑니다.

회원님을 알아볼 수 있는 정보(이메일·이름·사진)는 이 경우에도 모두 지워집니다.

언제 지워지나요

계정 정보즉시
집·물건·사진즉시 (혼자 쓰던 집인 경우)
휴지통에 있던 항목이미 지운 항목은 30일 뒤 자동으로 완전 삭제됩니다
백업운영상 보관하는 백업본에서는 최대 30일 안에 사라집니다

⚠ 삭제는 되돌릴 수 없습니다. 같은 이메일로 다시 가입하더라도 이전 데이터는 복구되지 않습니다.
