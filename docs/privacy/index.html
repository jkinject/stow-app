개인정보처리방침

어디뒀지 (Stow) · 시행일 2026년 9월 1일

English

먼저 요약합니다.

  • 이 앱은 광고를 넣지 않고, 분석 도구를 쓰지 않으며, 어떤 데이터도 판매하지 않습니다.
  • 광고 식별자·위치정보·연락처를 수집하지 않습니다.
  • 사진과 물건 목록은 같은 집(가구)에 속한 구성원에게만 보입니다.
  • 모든 데이터는 대한민국(AWS 서울 리전) 에 저장됩니다.

1. 수집하는 정보

가. 계정 정보

항목이메일 주소, 표시 이름, 프로필 사진 주소
수집 방법구글 계정으로 로그인할 때 구글이 제공하거나, 이메일 링크 로그인 시 직접 입력
이용 목적본인 확인, 같은 집 구성원에게 누가 무엇을 바꿨는지 표시

나. 이용자가 앱에 직접 넣는 정보

항목집·장소·박스·물건의 이름과 메모, 물건 사진, 수량, 구매 링크, 카테고리
이용 목적앱의 본래 기능(물건이 어디 있는지 기록하고 찾아주기)

다. 변경 이력

항목어떤 물건이 언제, 누구에 의해, 어떻게 바뀌었는지
이용 목적가족이 함께 쓰는 앱이므로 "누가 옮겼는지" 를 확인할 수 있게 하기 위함

라. 기기 정보

항목푸시 알림 토큰
이용 목적물건이 다 떨어졌을 때 등 알림 발송 (알림을 켠 경우에만)

2. 수집하지 않는 정보

  • 광고 식별자(AAID) — 수집하지 않습니다.
  • 위치정보(GPS) — 수집하지 않습니다.
  • 연락처, 통화기록, 문자메시지 — 수집하지 않습니다.
  • 이용 행태 분석 도구(Google Analytics 등) — 사용하지 않습니다.

3. 앱 권한

카메라물건 사진을 찍기 위해 사용합니다. 촬영한 사진만 저장되며, 촬영 중 화면은 저장되지 않습니다.
사진·미디어
(안드로이드 12 이하)		이미 찍어 둔 사진을 앨범에서 불러오기 위해 사용합니다. 선택한 사진만 읽습니다.
인터넷 / 네트워크 상태가족 간 데이터 동기화에 사용합니다.
진동알림 시 사용합니다.

권한은 해당 기능을 처음 쓸 때 요청하며, 거부하셔도 나머지 기능은 정상 동작합니다.

4. 처리 위탁 및 제3자 제공

개인정보를 판매하거나 광고 목적으로 제공하지 않습니다. 서비스 운영에 필요한 범위에서 아래 업체에 처리를 위탁합니다.

Supabase데이터베이스·로그인·사진 저장 / 보관 위치: 대한민국 서울(AWS ap-northeast-2)
Google구글 계정 로그인 처리 (선택한 경우에만)
Resend로그인 링크 이메일 발송 / 이메일 주소만 전달 (AWS 도쿄 경유)

5. 보유 기간과 파기

  • 지운 물건·박스·장소는 30일 동안 휴지통에 보관되어 복구할 수 있고, 30일이 지나면 자동으로 완전히 삭제됩니다.
  • 회원 탈퇴 시, 같은 집에 다른 구성원이 있으면 관리자 권한이 자동으로 넘어간 뒤 회원님의 계정 정보가 삭제됩니다. 남은 구성원이 없으면 그 집의 모든 데이터(물건·사진 포함)가 함께 삭제됩니다.
  • 삭제는 되돌릴 수 없습니다.

6. 이용자의 권리

회원님은 언제든지 아래 권리를 앱 안에서 직접 행사하실 수 있습니다.

  • 열람·수정 — 저장한 모든 내용은 앱에서 바로 보고 고칠 수 있습니다.
  • 삭제 — 개별 항목 삭제, 또는 더보기 → 탈퇴하기 로 계정 전체 삭제. 앱 없이 요청하는 방법은 계정 및 데이터 삭제 를 보세요.
  • 동의 철회 — 탈퇴가 곧 동의 철회입니다.

7. 안전성 확보 조치

  • 모든 통신은 HTTPS 로 암호화됩니다.
  • 데이터베이스에 행 수준 보안(RLS) 을 적용하여, 같은 집 구성원이 아니면 서버에서 조회 자체가 차단됩니다.
  • 사진은 비공개 저장소에 보관되며, 권한이 확인된 경우에만 짧은 시간 동안 유효한 주소가 발급됩니다.
  • 로그인은 PKCE 방식을 사용하여, 로그인 링크가 가로채여도 다른 기기에서는 사용할 수 없습니다.

8. 만 14세 미만 아동

이 앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 고의로 수집하지 않습니다.
