A few things worth knowing

Is Stow really free?

Yes. No ads, no subscription, no analytics trackers. Photos and lists are visible only to the members of your home.

Do I have to catalog my whole house?

No. Start with the things you actually lose: seasonal clothes, cables, documents, medicine. Add more whenever you put something away.

Can my family use the same home?

Yes. One invite code brings everyone into the same home. Every change is logged so you can see who moved what.

Do I need QR labels to use Stow?

No. Search works without them. Labels are optional: print 21 per A4 sheet, stick them on boxes, and scanning one opens that box’s contents.

Is there an iPhone version?

Not yet. Stow is on Android today; iOS is planned.
